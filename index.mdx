Shockly Shop is a production-ready, full-stack e-commerce platform built as a Bun monorepo. The backend is a NestJS + Fastify REST API backed by PostgreSQL (Drizzle ORM) and Redis (BullMQ), while the frontend is a Next.js storefront with an embedded admin dashboard. You can self-host the entire stack with Docker in minutes.

## Get Started

<Steps>
  <Step title="Clone and install dependencies">
    Clone the repository and install all workspace dependencies with a single command from the repo root.
  </Step>
  <Step title="Start infrastructure">
    Run Docker Compose to bring up PostgreSQL and Redis, then copy `.env.example` to `.env`.
  </Step>
  <Step title="Migrate and seed the database">
    Run `bun run db:migrate` followed by `bun run db:seed` to set up the schema and load sample data.
  </Step>
  <Step title="Start both apps">
    Run `bun run dev` from the repo root to start the API on port 3001 and the storefront on port 3002.
  </Step>
</Steps>

Read the [full quickstart guide](/quickstart) for detailed commands and verification steps.

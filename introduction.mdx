Shockly Shop is an open-source, self-hosted e-commerce platform built for developers who need complete ownership of their storefront and data. Rather than adapting a hosted SaaS to your requirements, Shockly Shop gives you a production-ready monorepo — a NestJS + Fastify REST API backed by PostgreSQL and Redis, paired with a Next.js storefront — that you can clone, run locally in minutes, and extend without limits. It targets indie developers, agencies, and engineering teams who want a real codebase to build on rather than a black-box subscription.

## What You Get

<CardGroup cols={2}>
  <Card title="REST API" icon="server">
    A NestJS 10 + Fastify API with a global `/api` prefix, request validation via `class-validator`, a unified response interceptor, and rate-limiting out of the box. All endpoints are documented in an interactive Swagger UI at `/api/docs`.
  </Card>
  <Card title="Admin Dashboard" icon="layout-dashboard">
    A full-featured Next.js admin panel for managing products, categories, orders, and users. Protected by JWT authentication, it lets you upload product images, apply discounts, and track order status from one place.
  </Card>
  <Card title="Customer Storefront" icon="store">
    A Next.js 16 storefront (Pages Router) running on port 3002. It features infinite scroll product listings, a filterable category browser, a shopping cart backed by Redux Persist, and a full checkout flow.
  </Card>
  <Card title="Background Jobs" icon="clock">
    BullMQ job queues powered by Redis handle async workloads — such as order processing and notifications — keeping API response times fast and side effects out of the request cycle.
  </Card>
  <Card title="Discount Codes" icon="tag">
    A built-in discount code engine lets you create coupon codes with percentage or flat-value rules. The seeded `WELCOME10` code (10% off, no minimum order) is ready to test on first boot.
  </Card>
  <Card title="Payment Abstraction" icon="credit-card">
    The checkout module is structured as a payment-provider abstraction layer, making it straightforward to wire in Stripe, PayPal, or any other gateway without restructuring the order pipeline.
  </Card>
</CardGroup>

## Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| Runtime | Bun 1.3+ | JavaScript runtime and package manager for both apps |
| API Framework | NestJS 10 + Fastify | Modular, decorator-driven REST API with high-throughput HTTP |
| ORM | Drizzle | Type-safe SQL schema definition, migrations, and queries |
| Database | PostgreSQL 16 | Primary relational data store (products, orders, users) |
| Cache / Queue | Redis + BullMQ | Session caching, rate-limit counters, and async job queues |
| Frontend | Next.js 16 | Customer storefront and admin dashboard (Pages Router) |
| State | React Query + Redux Toolkit | Server-state fetching/caching and global client-state management |
| UI | shadcn/ui + Tailwind CSS | Accessible component primitives styled with utility-first CSS |
| Auth | JWT (access + refresh) | Short-lived access tokens (15 m) paired with rotating refresh tokens (7 d) |

## Repo Structure

Shockly Shop is a Bun workspace monorepo. All dependencies are installed once from the root with a single `bun.lock` file shared across both apps.

```text
shockly-full/
├── package.json          # Workspace root — shared scripts (dev, build, db:*)
├── bun.lock              # Single lockfile for the entire monorepo
├── apps/
│   ├── api/              # @shockly/api — NestJS + Fastify backend (port 3001)
│   │   ├── src/
│   │   │   ├── main.ts   # Bootstrap: Fastify adapter, Swagger, CORS, global pipes
│   │   │   ├── app.module.ts
│   │   │   ├── db/       # Drizzle schema, migrations, seed script
│   │   │   └── ...       # Feature modules (products, orders, auth, …)
│   │   ├── docker-compose.yml  # Postgres 16 + Redis 7 containers
│   │   └── .env.example
│   └── web/              # @shockly/web — Next.js storefront + admin (port 3002)
│       ├── src/
│       │   ├── api/      # Axios client + API constants (baseURL)
│       │   ├── pages/    # Next.js Pages Router
│       │   └── ...
│       └── package.json
└── ...
```

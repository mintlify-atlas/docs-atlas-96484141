Most discount endpoints are restricted to **admin** users (`GET /api/discounts`, `POST /api/discounts`, `DELETE /api/discounts/:id`). The one public endpoint — `POST /api/discounts/validate` — requires no authentication and is designed to be called from the storefront at checkout to calculate the effective discount before an order is placed.

Codes are stored in **uppercase** regardless of how they are submitted. The service will automatically normalise any lowercase input before querying or inserting.

<Note>
  `usedCount` increments each time a discount code is successfully applied to a completed order. When `usedCount` reaches `maxUses` the code is considered exhausted and `POST /api/discounts/validate` will return `400`.
</Note>

## List all discount codes (admin)

```bash
GET /api/discounts
```

Returns all discount codes in the system. Requires the `admin` role.

<ParamField header="Authorization" type="string" required>
  `Bearer <accessToken>` — must belong to an admin user.
</ParamField>

**Response `200`**

```json
{
  "data": {
    "discounts": [
      {
        "id": "c3d4e5f6-0000-0000-0000-000000000001",
        "code": "WELCOME10",
        "type": "percentage",
        "value": "10.00",
        "minOrderAmount": "0.00",
        "maxUses": null,
        "usedCount": 42,
        "isActive": true,
        "expiresAt": null,
        "createdAt": "2024-01-01T00:00:00.000Z",
        "updatedAt": "2024-06-01T00:00:00.000Z"
      }
    ]
  }
}
```

**curl example**

```bash
curl -X GET https://api.shockly.shop/api/discounts \
  -H "Authorization: Bearer <adminAccessToken>"
```

## Create a discount code (admin)

```bash
POST /api/discounts
```

Creates a new discount code. Returns `409 Conflict` if a code with the same value (case-insensitive) already exists.

<ParamField header="Authorization" type="string" required>
  `Bearer <accessToken>` — must belong to an admin user.
</ParamField>

<ParamField body="code" type="string" required>
  The promo code string (e.g. `"SUMMER25"`). Stored as uppercase. Must be unique.
</ParamField>

<ParamField body="type" type="string (enum)" required>
  Discount calculation type. One of `"percentage"` or `"fixed"`.
</ParamField>

<ParamField body="value" type="number" required>
  Discount value. For `"percentage"` type, this is a percentage between `0` and `100`. For `"fixed"` type, this is an absolute currency amount.
</ParamField>

<ParamField body="minOrderAmount" type="number">
  Optional minimum order subtotal required to apply the code. Defaults to `0` (no minimum).
</ParamField>

<ParamField body="maxUses" type="number">
  Optional maximum number of times this code can be used across all orders. `null` (or omitted) means unlimited uses.
</ParamField>

<ParamField body="expiresAt" type="string (ISO 8601 date)">
  Optional expiry date-time. After this timestamp the code will be rejected. `null` (or omitted) means the code never expires.
</ParamField>

**Request body**

```json
{
  "code": "SUMMER25",
  "type": "percentage",
  "value": 25,
  "minOrderAmount": 500000,
  "maxUses": 200,
  "expiresAt": "2024-09-01T00:00:00.000Z"
}
```

**Response `201`**

```json
{
  "data": {
    "discount": {
      "id": "d4e5f6a7-0000-0000-0000-000000000002",
      "code": "SUMMER25",
      "type": "percentage",
      "value": "25.00",
      "minOrderAmount": "500000.00",
      "maxUses": 200,
      "usedCount": 0,
      "isActive": true,
      "expiresAt": "2024-09-01T00:00:00.000Z",
      "createdAt": "2024-06-15T12:00:00.000Z",
      "updatedAt": "2024-06-15T12:00:00.000Z"
    }
  }
}
```

**curl example**

```bash
curl -X POST https://api.shockly.shop/api/discounts \
  -H "Authorization: Bearer <adminAccessToken>" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "SUMMER25",
    "type": "percentage",
    "value": 25,
    "minOrderAmount": 500000,
    "maxUses": 200,
    "expiresAt": "2024-09-01T00:00:00.000Z"
  }'
```

## Validate a discount code (public)

```bash
POST /api/discounts/validate
```

Checks whether a discount code is valid for a given order amount and returns the computed discount. No authentication is required — this endpoint is intended to be called from the storefront checkout page before creating an order.

The endpoint returns `400 Bad Request` for any of the following reasons:
- The code does not exist or `isActive` is `false`.
- The code has passed its `expiresAt` date.
- `usedCount` has reached `maxUses`.
- The provided `orderAmount` is below the code's `minOrderAmount`.

<ParamField body="code" type="string" required>
  The discount code to validate (case-insensitive).
</ParamField>

<ParamField body="orderAmount" type="number" required>
  The current order subtotal (before discount) in the store's base currency unit.
</ParamField>

**Request body**

```json
{
  "code": "WELCOME10",
  "orderAmount": 25000000
}
```

**Response `200` — valid code**

```json
{
  "data": {
    "valid": true,
    "discountAmount": 2500000,
    "finalAmount": 22500000,
    "discount": {
      "id": "c3d4e5f6-0000-0000-0000-000000000001",
      "code": "WELCOME10",
      "type": "percentage",
      "value": "10.00",
      "minOrderAmount": "0.00",
      "maxUses": null,
      "usedCount": 42,
      "isActive": true,
      "expiresAt": null,
      "createdAt": "2024-01-01T00:00:00.000Z",
      "updatedAt": "2024-06-01T00:00:00.000Z"
    }
  }
}
```

**Response `400` — invalid / expired / exhausted code**

```json
{
  "status": "error",
  "statusCode": 400,
  "message": "کد تخفیف منقضی شده"
}
```

**curl example**

```bash
curl -X POST https://api.shockly.shop/api/discounts/validate \
  -H "Content-Type: application/json" \
  -d '{"code": "WELCOME10", "orderAmount": 25000000}'
```

<Tip>
  The database is seeded with a **`WELCOME10`** discount code — 10% off with no minimum order amount and unlimited uses (`maxUses: null`). Use it freely during development and testing to exercise the validation and order flows.
</Tip>

## Delete a discount code (admin)

```bash
DELETE /api/discounts/:id
```

Permanently removes a discount code by its UUID. Returns `404` if the code does not exist.

<ParamField path="id" type="string (UUID)" required>
  UUID of the discount record to delete.
</ParamField>

**Response `200`**

```json
{
  "data": {
    "discount": {
      "id": "d4e5f6a7-0000-0000-0000-000000000002",
      "code": "SUMMER25"
    }
  }
}
```

**curl example**

```bash
curl -X DELETE https://api.shockly.shop/api/discounts/d4e5f6a7-0000-0000-0000-000000000002 \
  -H "Authorization: Bearer <adminAccessToken>"
```

## Discount schema

<ResponseField name="id" type="string (UUID)">
  Unique identifier of the discount record.
</ResponseField>

<ResponseField name="code" type="string">
  The promo code string, always stored in uppercase (max 50 characters).
</ResponseField>

<ResponseField name="type" type="string (enum)">
  `"percentage"` — deducts a percentage of the order total. `"fixed"` — deducts a flat currency amount.
</ResponseField>

<ResponseField name="value" type="string (numeric)">
  The discount magnitude. Percentage value (0–100) for `percentage` type, or absolute amount for `fixed` type. Stored as a decimal string with 2 decimal places.
</ResponseField>

<ResponseField name="minOrderAmount" type="string (numeric)">
  Minimum order subtotal required before this code can be applied. `"0.00"` means no minimum.
</ResponseField>

<ResponseField name="maxUses" type="number | null">
  Maximum total number of uses allowed across all orders. `null` means unlimited.
</ResponseField>

<ResponseField name="usedCount" type="number">
  Running total of how many times the code has been successfully applied to an order. Increments atomically via `applyDiscount()`.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  When `false` the code is disabled and `validate` will reject it regardless of other fields.
</ResponseField>

<ResponseField name="expiresAt" type="string (ISO 8601) | null">
  Date-time after which the code is considered expired. `null` means the code never expires.
</ResponseField>

<ResponseField name="createdAt" type="string (ISO 8601)">
  Timestamp when the discount code was created.
</ResponseField>

<ResponseField name="updatedAt" type="string (ISO 8601)">
  Timestamp of the most recent update to this record.
</ResponseField>

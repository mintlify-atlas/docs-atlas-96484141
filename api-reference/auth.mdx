sidebarTitle: "Auth"

The Auth module handles all identity-related operations in Shockly Shop. Every endpoint lives under `/api/auth`. Signup and login return both an **access token** (short-lived) and a **refresh token** (long-lived) together with the sanitized user object. Protected endpoints such as `token` and `logout` require you to pass the appropriate JWT in the `Authorization: Bearer <token>` header.

---

## POST /api/auth/signup

Register a new customer account. Returns a token pair and the newly created user. Responds with `409 Conflict` if the username is already taken.

### Request body

<ParamField body="firstname" type="string" required>
  The user's first name (e.g. `"Ali"`).
</ParamField>

<ParamField body="lastname" type="string" required>
  The user's last name (e.g. `"Rezaei"`).
</ParamField>

<ParamField body="username" type="string" required>
  A unique username that will identify the account (e.g. `"ali123"`).
</ParamField>

<ParamField body="password" type="string" required>
  Plain-text password. Must be at least **6 characters** long. The API stores a bcrypt hash — the raw value is never persisted.
</ParamField>

<ParamField body="phoneNumber" type="string">
  Optional mobile number (e.g. `"09123456789"`).
</ParamField>

<ParamField body="address" type="string">
  Optional delivery address (e.g. `"Tehran, Valiasr Street"`).
</ParamField>

### Example request

```bash
curl -X POST https://api.shockly.shop/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "firstname": "Ali",
    "lastname": "Rezaei",
    "username": "ali123",
    "password": "secret123",
    "phoneNumber": "09123456789",
    "address": "Tehran, Valiasr Street"
  }'
```

### Example response `201 Created`

```json
{
  "status": "success",
  "data": {
    "token": {
      "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    },
    "user": {
      "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "firstname": "Ali",
      "lastname": "Rezaei",
      "username": "ali123",
      "phoneNumber": "09123456789",
      "address": "Tehran, Valiasr Street",
      "role": "customer",
      "createdAt": "2024-06-01T10:00:00.000Z",
      "updatedAt": "2024-06-01T10:00:00.000Z"
    }
  }
}
```

## POST /api/auth/login

Authenticate an existing user with their username and password. Returns a fresh token pair and the user object. Responds with `401 Unauthorized` when credentials are invalid.

### Request body

<ParamField body="username" type="string" required>
  The account's unique username.
</ParamField>

<ParamField body="password" type="string" required>
  The account's plain-text password.
</ParamField>

### Example request

```bash
curl -X POST https://api.shockly.shop/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "ali123",
    "password": "secret123"
  }'
```

### Example response `200 OK`

```json
{
  "status": "success",
  "data": {
    "token": {
      "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    },
    "user": {
      "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "firstname": "Ali",
      "lastname": "Rezaei",
      "username": "ali123",
      "phoneNumber": "09123456789",
      "address": "Tehran, Valiasr Street",
      "role": "customer",
      "createdAt": "2024-06-01T10:00:00.000Z",
      "updatedAt": "2024-06-01T10:00:00.000Z"
    }
  }
}
```

## POST /api/auth/token

Exchange a valid **refresh token** for a brand-new access/refresh token pair. Pass the refresh token as a Bearer token in the `Authorization` header. The old refresh token is invalidated and replaced. Responds with `401 Unauthorized` if the token is expired or invalid.

### Request headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer <refreshToken>` |

### Example request

```bash
curl -X POST https://api.shockly.shop/api/auth/token \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

### Example response `200 OK`

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

## POST /api/auth/logout

Invalidate the current session by clearing the refresh token stored server-side. Pass the **access token** in the `Authorization` header. After logging out, calling `POST /api/auth/token` with any previously issued refresh token will fail.

### Request headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer <accessToken>` |

### Example request

```bash
curl -X POST https://api.shockly.shop/api/auth/logout \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

### Example response `200 OK`

```json
{
  "status": "success"
}
```

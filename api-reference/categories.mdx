The Categories and Subcategories modules define the product taxonomy used throughout Shockly Shop. **Category** is the top-level grouping (e.g. *Mobile Phones*, *Laptops*); **Subcategory** is a child of a category (e.g. *Android*, *iOS*). Both read endpoints are fully public, while create and delete require an `admin` access token. Subcategory records store a direct reference to their parent category UUID through the `category` field.

---

## Categories

### GET /api/categories

Return all categories in the store. This endpoint is public — no authentication required.

#### Example request

```bash
curl https://api.shockly.shop/api/categories
```

#### Example response `200 OK`

```json

    "categories": [
```

### GET /api/categories/:id

Retrieve a single category by its UUID. Returns `404 Not Found` when the category does not exist.

#### Path parameters

<ParamField path="id" type="string (UUID)" required>

</ParamField>

#### Example request

```bash

```

#### Example response `200 OK`

```json
{
```

### POST /api/categories

Create a new category. **Admin only.** Returns `409 Conflict` if a category with the same name already exists.

#### Request headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer <accessToken>` |

#### Request body

<ParamField body="name" type="string" required>
  Human-readable category name (e.g. `"Mobile Phones"`). Must be unique across the store.
</ParamField>

<ParamField body="icon" type="string">
  Optional icon character or string to visually represent the category in the UI (e.g. `"📱"`).
</ParamField>

#### Example request

```bash
curl -X POST https://api.shockly.shop/api/categories \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tablets",
    "icon": "📟"
  }'
```

#### Example response `201 Created`

```json
{
  "data": {
    "category": {
      "id": "b3e1f2a0-1234-5678-abcd-000000000003",
      "name": "Tablets",
      "slugname": "tablets",
      "icon": "📟",
      "createdAt": "2024-07-01T12:00:00.000Z",
      "updatedAt": "2024-07-01T12:00:00.000Z"
    }
  }
}
```

## Category schema

<ResponseField name="id" type="string (UUID)">
  Unique identifier for the category, auto-generated by the database.
</ResponseField>

<ResponseField name="name" type="string">
  Human-readable name. Unique across all categories. Maximum 100 characters.
</ResponseField>

<ResponseField name="slugname" type="string">
  URL-safe slug automatically derived from `name` (e.g. `"mobile-phones"`). Maximum 120 characters.
</ResponseField>

<ResponseField name="icon" type="string | null">
  Optional icon string for UI display. Maximum 255 characters.
</ResponseField>

<ResponseField name="createdAt" type="string (ISO 8601)">
  Timestamp when the category was created.
</ResponseField>

<ResponseField name="updatedAt" type="string (ISO 8601)">
  Timestamp of the most recent update.
</ResponseField>

## Subcategories

### GET /api/subcategories

Return subcategories, optionally filtered by parent category UUID and capped by a limit. This endpoint is public — no authentication required.

#### Query parameters

<ParamField query="category" type="string (UUID)">
  Filter results to only subcategories that belong to this category UUID.
</ParamField>

<ParamField query="limit" type="string" default="100">
  Maximum number of subcategories to return.
</ParamField>

#### Example request

```bash
curl "https://api.shockly.shop/api/subcategories?category=b3e1f2a0-1234-5678-abcd-000000000001&limit=10"
```

#### Example response `200 OK`

```json
{
  "data": {

      {
        "id": "c4f2a3b1-2345-6789-bcde-000000000001",

        "createdAt": "2024-01-15T00:00:00.000Z",
        "updatedAt": "2024-01-15T00:00:00.000Z"
      },
      {
        "id": "c4f2a3b1-2345-6789-bcde-000000000002",
```

### POST /api/subcategories

Create a new subcategory under an existing category. **Admin only.** Returns `409 Conflict` if a subcategory with the same slug already exists.

#### Request headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer <accessToken>` |

#### Request body

<ParamField body="name" type="string" required>
  Human-readable subcategory name (e.g. `"Android"`).
</ParamField>

<ParamField body="category" type="string (UUID)" required>
  The UUID of the parent category this subcategory belongs to. The parent category must exist; deleting a parent category will cascade-delete all its subcategories.
</ParamField>

#### Example request

```bash
curl -X POST https://api.shockly.shop/api/subcategories \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Android",
    "category": "b3e1f2a0-1234-5678-abcd-000000000001"
  }'
```

#### Example response `201 Created`

```json
{
  "data": {
    "subcategory": {
      "id": "c4f2a3b1-2345-6789-bcde-000000000003",
      "name": "Android",
      "slugname": "android",
      "category": "b3e1f2a0-1234-5678-abcd-000000000001",
      "createdAt": "2024-07-01T12:30:00.000Z",
      "updatedAt": "2024-07-01T12:30:00.000Z"
    }
  }
}
```

---

<Tip>
  The `id` values of both categories and subcategories can be passed directly as query parameters when browsing the product catalog. Use `GET /api/products?category=<categoryId>` to filter by category, or add `&subcategory=<subcategoryId>` to narrow down to a specific subcategory. See the [Products API](/api-reference/products) for the full list of supported query parameters.
</Tip>
